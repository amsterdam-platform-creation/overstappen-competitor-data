# Overstappen Competitor Data - Cashback Rate Scraping System

Weekly automated scraping of competitor cashback rates from CashbackXL.

## Quick Start

```bash
# Test scraper on 5 sample providers
npm run scrape:test

# Scrape all providers (78 providers, ~2 minutes)
npm run scrape:providers

# Scrape comparison sites (8 sites, ~15 seconds)
npm run scrape:comparison-sites

# Scrape everything (both tracks)
npm run scrape:all

# Compare rates and generate reports (default: includes all sources)
npm run compare

# Compare with CashbackXL priority (only uses CashbackXL, falls back to Woolsocks.eu if needed)
npm run compare:cashbackxl
```

## Output Files

### Raw Scraped Data

**cashbackxl-providers-raw.csv** - Provider-specific deals (Track 1)
- Columns: `provider`, `deal_description`, `cashback_amount`, `category`, `source_url`, `scraped_at`, `confidence`
- Example: `Engie, "Gas + elektriciteit 1 jaar vast", €40.00, energy, https://..., 2025-11-11T10:00:00Z, high`

**cashbackxl-comparison-sites-raw.csv** - Generic comparison site deals (Track 2)
- Columns: `comparison_site`, `deal_description`, `cashback_amount`, `category`, `applies_to`, `source_url`, `scraped_at`, `confidence`
- Example: `Independer Energie, "Op het afsluiten van een energiecontract", €18.00, energy, ALL_PROVIDERS, https://..., 2025-11-11T10:00:00Z, high`

### Processed Data

**competitors-mapped.csv** - Mapped competitor rates with standardized contract types
- Columns: `source`, `vertical`, `entity_type`, `entity_name_canonical`, `offer_type`, `amount`, `description`, `url`, `last_seen_at`
- Used for comparison against Woolsocks rates

**woolsocks-normalized.csv** - Normalized Woolsocks rates from Overstappen data
- Columns: `source`, `vertical`, `entity_type`, `entity_name_canonical`, `offer_type`, `amount`, `description`, `url`, `last_seen_at`
- Standardized format for comparison

### Reports

**comparison-report.md** - Detailed comparison of all offers with recommendations
- Shows current rates vs best competitor rates
- Includes margin analysis and action recommendations
- **Default mode:** Compares against best rate from ALL sources (CashbackXL + Woolsocks.eu)
- Generated by `npm run compare`

**comparison-report-cashbackxl-priority.md** - Alternative analysis prioritizing CashbackXL
- **CashbackXL Priority mode:** Only uses CashbackXL deals first, falls back to Woolsocks.eu only if no CashbackXL alternative exists
- Useful when focusing specifically on CashbackXL as the primary competitor
- Generated by `npm run compare:cashbackxl`

**woolsocks-vs-cashbackxl-report.md** - Focused comparison with CashbackXL only
- Highlights reduction opportunities (offers that can be lowered)
- Shows offers already matching or below CashbackXL rates
- Generated by separate script: `compare-woolsocks-vs-cashbackxl.js`

## Comparison Analysis Modes

The system supports two analysis modes for comparing rates:

### Default Mode (`npm run compare`)
- Compares against the **best rate from ALL sources** (CashbackXL + Woolsocks.eu)
- Takes the maximum rate across all competitor sources
- Best for: Understanding overall market competitiveness

### CashbackXL Priority Mode (`npm run compare:cashbackxl`)
- **Prioritizes CashbackXL deals** (both provider-specific and generic comparison sites)
- Only uses Woolsocks.eu rates as a fallback when no CashbackXL alternative exists
- Best for: Focusing specifically on CashbackXL as the primary competitor
- Generates: `comparison-report-cashbackxl-priority.md` and `comparison-results-cashbackxl-priority.csv`
